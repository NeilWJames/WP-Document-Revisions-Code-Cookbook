Add-on to WP Document Revisions to support PublishPress Revisions.

== Description ==

This plugin is an add-on to WP Document Revisions to integrate with PublishPress Revisions.

== Installation ==

1. Download the Cookbook code from GitHub
2. Copy the `wpdr-revisionary` directory to your plugins directory. This can be done by creating a zip file of the directory and loading that as a plugin.
3. Activate the plugin through the 'Plugins' menu in WordPress
